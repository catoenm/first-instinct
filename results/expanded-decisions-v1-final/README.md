# Closed expanded decision comparison

The [full report](../../docs/expanded-decisions-v1-results.md) describes all three
methods and both seeds. No method passed the prospective joint transfer gate.
The original supervised demo remains unchanged.

`audit.json` is the independent reconstructed result. `checkpoint-audit.json`
verifies identical starts and selected/latest weights; `advancement.json`
applies the frozen joint criteria; `consumption.json` separates actual objective
presentations, exact token inputs, task identities and diagnostics.
`forecast-provenance.json` counts referenced preexecuted label branches.

The public receipt archive contains 281 files (30,358,046 bytes),
excluding weights and credentials. `receipt-hashes.json` lists every archived
file; `receipt-archive.json` records its size and SHA256. Its complete contents
were rehashed after packaging. The 514-file full local archive, including model
weights, was separately verified before provider deletion.

`reporter-correction/` preserves the first failed offline audit and original
reporting code. Its calendar task-count schema bug was fixed with regression
coverage, then all development and final receipts were reconstructed again.
Neither training nor frozen evaluation data changed.

`provider-billing.json` records accrued charges that may lag the recovery
restart. `cloud-collection.json` separately records the compute estimate and
confirmed pod deletion. No stopped interval is counted as running GPU time.
The original cumulative $500 and $40 pilot allocation remain the only budgets.

Calendar is now an exposed diagnostic mechanism. It cannot be reused as an
untouched test for a subsequent recipe. These authored priors and twelve
related databases do not establish broad generalization or Jev parity.
