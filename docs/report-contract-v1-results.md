# Public tool contracts qualified without changing outcome labels

The proposed explicit report-tool contract passes the local execution-receipt and
input-coverage checks. All 308 augmented forecast questions fit both model
interfaces without truncation. **No model has scored the augmented inputs yet.**
This prepares a diagnostic of the missing-contract hypothesis; it does not confirm
why the previous models made their errors.

The current prompts give brief tool descriptions. The frozen implementation has
additional consequential rules: each repair computes its chosen target's result
from the current file, a successful repair ends the attempt immediately, and an
inspection-service outage blocks inspection but does not block a ready write.
The new contract states these rules, along with lock/preparation failures, control
effects, turn limits and costs. The same text is appended to every original state;
questions and option descriptions remain byte-for-byte unchanged.

## What the audit checked

The auditor reconstructed **756 existing report branches**, including 1,936
command presentations and 1,300 actor transitions. Independently derived public
mechanics matched every recorded return code, control-state effect, cost and
terminal flag. These historical executions include 36 successful writes while
inspection was offline, 12 failed inspection calls, and 48 writes refused for
unsatisfied prerequisites. They are not newly executed branches or independent
new tasks.

All grouped forecast targets reproduce from 504 existing source branches. The
196 forecast groups with multiple compatible source worlds receive identical
augmented text. The contract never consumes hidden file contents, preferred target,
future observations, a forecast target or a model prediction. Four tests cover
exact reversibility, private-field rejection, separate failure dependencies,
terminal limits and constant descriptions across changed public goals.

Native Laya formatting matched the pinned reference on all 616 original/augmented
presentations. All 308 augmented inputs retain complete information: maximum 918
Laya tokens and 1,051 Qwen tokens, within the unchanged limits. No foundation model
was loaded on the Mac. The guarded job took about five seconds, sampled less than
0.63 GiB resident memory and added no swap.

## Next controlled question

Freeze a paired, inference-only diagnostic using the same three fixed checkpoints
and the entire original/augmented cohort. Keep calibration, labels, option order
and scoring unchanged, and distinguish the effect of supplying tool information
from the effect of training. Improvement would be evidence about this exposed
workflow's interface. It would not demonstrate new-mechanism transfer or qualify
a release checkpoint.

The original baseline and its unfavorable supervised result remain intact. This
stage spent no GPU budget. Broader executable mechanisms remain the data priority;
explicit contracts should be a requirement for those environments as well.
