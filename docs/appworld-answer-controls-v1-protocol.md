# Same-cost answer alternatives

Before model inference, extend the reference-assisted query tasks with a wrong
answer candidate of the same type. Find the correct reference answer among prior
public business-tool responses. Select a different already observed value from
the same application, API and terminal field name, preserving its Python type.
Do not invent a hidden identifier or use a value seen only later. If no such
candidate exists, do not create this intervention.

Execute the same task-completion command with that alternative answer, preserving
the entire prior history and other calls. Independently replay it. Require an
identical observed prefix, matching replay, clean verifier rejection, and identical
non-supervisor table hashes to the successful reference. An exception is missing
truth, never a wrong-answer label.

This supplies equal-length, equal-cost plans whose correctness depends on the
goal and observations, rather than just presence of a completion call. It is
separate from dynamic proposal-quality evaluation. Only existing upstream TRAIN
instances and frozen program roles may enter this extension. At most one answer
intervention per task, or 58 additional worlds with independent replay, keeps
the full collection under the previously declared 608-world local ceiling.

Use these wrong-answer plans alongside stopping and verified successful plans
in menus of at most four options. The same execution receipts supply consequence
forecasts. Count each new branch and replay separately; menu, cost and question
variants are presentations of those worlds, not new underlying tasks.
