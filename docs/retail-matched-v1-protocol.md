Preserve their results and every earlier freeze. Use the unchanged pinned real

## Prospective distribution

Choose each of the three existing goals with equal weight, each of the six
qualified read/write fee pairs with equal weight, and every compatible condition
within that goal uniformly. The two address goals have eight conditions each;
payment migration has four. Equal sampling of all 20 goal/condition pairs would
underweight payment migration and would not implement this declared goal prior.

A complete prospective learning block therefore has 144 reset presentations:
48 per goal, with eight presentations per goal/fee cell. Address conditions appear
once per cell; payment conditions appear twice. The second payment presentation
is a repeat, not another independent task or world. Produce deterministic shuffled
blocks for seeds 20260924 and 20260925. Every future comparison arm must receive
the same ordered block within a seed. These are prepared reset identities, not
collected on-policy trajectories or consumed training data.

## Bounded execution qualification

Execute all 120 distinct goal/condition/fee cells with two scripted controllers:
stop immediately, and inspect then take the goal-appropriate write when the real
public responses satisfy its prerequisites. The controller reads only public
observations and ignores fees deliberately; it is a diagnostic, not an optimal
policy or a source of next-action training targets. It replans through individual
commands rather than receiving a private world identifier.

This produces 240 primary reset executions. Add twelve independent replay resets:
both controllers on each goal's first declared condition at the lowest and highest
fee pair. Other cells have no new replay in this stage; the earlier runtime stage
already replayed each world/controller path under its assigned fee. Total ceiling:
252 resets, 1,512 actor turns and tool attempts, six turns per episode, 30 seconds
per worker response and 60 seconds per episode. Use one worker at a time under the
existing 4-GiB/30-minute/normal-pressure/512-MiB-new-swap local supervisor.

Require every recorded command and response, complete terminal state and verifier
result to agree with the already executed fixed procedure from the identical
initial world. Independently recalculate each attempt's fee and terminal payout;
reads, refused writes and repeated operations are never free. Check the complete
execution journal, imported source hashes and isolation receipts. Compare replay
states, inputs, outcomes and rewards exactly. Infrastructure errors stop the
stage and preserve partial output; they never become task-failure labels.

Within each goal/fee/controller cell, initial actor inputs must be identical across
hidden worlds. Keep legitimate differences in verified outcomes. For the same
goal/condition/controller, changing fees must not change executed tools or final
state under these deliberately cost-blind controllers. Expected returns use each
goal's uniform compatible-world prior; replays receive no extra probability mass.
Require that inspecting beats stopping at the lowest costs and stopping beats
inspecting at the highest costs for each goal. This compares only these two
controllers, not every available policy.

Re-encode every pre-action input with the pinned tokenizer; reject anything above
4,096 tokens without cropping. This covers these observed paths, not every path a
learned actor could take. Independent saved-receipt auditing must reproduce the
distribution, rewards, source agreement and aggregate counts.
