# Qualify an evidence interface before revising rejected transfer admission

Preserve the rejected transfer-v1 preparation, all executed branches and the
closed supervised run. This is a bounded local qualification of missing public
evidence and lossless representation. It performs no model inference, training,
new task selection or hardware rental. The original and development-selected
update-40 adapters remain the only prospective model pair.

## Public clock evidence

For each of the four already qualified reserved task instances, open two fresh
local worlds with the same fixed seed and application state. Do not load ground
truth. Read the public `phone.get_current_date_and_time` interface at the start
and immediately before each of the two existing history points. Replay only the
previously recorded prefix needed to reach those points. Compare every replayed
response with the existing trace, the initial state with the existing capture,
and each history-point state with its existing stopping branch. Require every
clock read to preserve all semantic database records and both independent worlds
to return identical clock observations and state hashes.

This adds at most eight world executions, each at most 96 simulated application
calls and 90 environment seconds, with a 120-second process deadline. Block
outgoing sockets and inherited service credentials. These are evidence-read
controls, not new task instances or alternative-outcome labels. Clock reads are
part of observed history; utility still concerns additional offered calls after
that history. A failed equivalence check rejects evidence augmentation rather
than silently reusing old outcome labels under a changed state.

## Explicit argument witnesses

Include complete public API documentation and the separately qualified finite
membership parser. Numerical ranges do not ground arbitrary amounts. For an
amount, permit only an exact currency literal from an earlier public response,
with source call, response path, text span and decimal value. Do not read secrets,
later responses, private task solutions or terminal outcomes to create witnesses.

For relative dates, use only the verified public clock and explicit words in the
visible goal: today, yesterday, or last N days including today. Record the goal
span, clock observation and exact calendar-day offset. Validate calendar math
independently against a second date implementation and year/month/leap boundaries.
Unsupported language or arithmetic remains rejected. Proof that a value is
available is distinct from proof that selecting that value achieves the task.

Apply checks at the time of each historical call as well as at each supplied
continuation. A fact learned later cannot justify an earlier command. Expose the
clock and argument witnesses in model-visible state; do not label derived values
as API defaults. Require witness mutations, future references and wrong values to
fail. Keep immediate and continuation success distinct and never use model
predictions as truth.

## Lossless shared representation

Test a deterministic catalog of exactly repeated JSON subtrees across visible
history and offered command descriptions. Every catalog reference must resolve
back to the original value, including value types, null versus missing fields,
record order, every record and every command. Catalog order must depend only on
public content, never on labels or outcome quality. Reject reserved-tag spoofing,
invalid references and cycles. No semantic summarization, opaque compression,
hidden evidence, truncation or removal of inconvenient records is allowed.

A reference is a representation of an ordinary API command, not a new command
and not a cost-free action. Exact decoding must preserve plan call counts, public
histories, action identities, utilities and forecast/decision joins. Fixed
controller behavior on decoded inputs must match the original representation.
Both model checkpoints will receive the same new representation if it qualifies.
Format changes are reported explicitly; they do not prove prediction invariance.

Use authored mechanics fixtures before examining sizing results, then inspect
all eight declared histories without selecting favorable replacements. Preserve
every failed qualification. Only after these checks pass may a separately frozen
transfer-v2 admission reuse the existing branch labels. It must still retain all
four programs with useful paired menus and positive alternatives within 8,192
tokens, and satisfy the unchanged split and source-provenance rules. This protocol
does not admit questions, relax that gate or authorize blind repeated attempts.
