# Reserved tool and telecom evaluation, before model scores

Prepare this cohort while history-pilot-v1 is running. Do not change that run,
its development selection, or any inherited data ownership. No reserved model
scores may be opened until a completed, independently audited pilot supplies a
qualifying checkpoint selected solely on its existing development criteria.
If no checkpoint qualifies, keep this evaluation unscored. A future candidate
requires a new explicit selection receipt, never selection using these scores.

Use every one of the 2,431 admitted TOUCAN reserved questions, spanning 38 source
server groups. Preserve their exact primary prompts, tool menus and labels. These
measure agreement with a demonstrated first action, not verified task completion.
Unknown semantic duplication and foundation pretraining exposure remain possible.

Also retain all 34 telecom reserved questions under the corrected evaluation-only
usage manifest. Device and allowance belong to one connected ownership component;
roaming's 17 development questions must not enter this test. Keep original source
role fields as provenance and honor the stricter corrected role. The small telecom
set is a verified workflow diagnostic, not an independent 34-task benchmark or
the official conversational benchmark. Reuse its independently checked execution
receipts and explicit four-world priors; perform no new executions during packing.

Keep immediate command-then-stop and specified-continuation forecasts separate.
For procedure decisions, compute the chosen procedure's expected utility from
saved verified outcomes, billed changes and declared action fees. Any utility-maximizing
procedure is an acceptable choice: its tie distribution is not a success forecast.
Observation-value questions retain their deterministic expected-utility labels.
Do not use model probabilities as execution labels or rewards.

Add one reversed-option presentation per question as a paired diagnostic, mapping
targets and utilities by option identity. Exclude only reversed presentations that
exceed 4,096 tokens; never drop or crop their primary questions. Report the matched
subset and complete original cohort separately. Count these as presentations of
the same underlying questions. Audit role, exact source tokens, corrected usage,
target alignment and token overlap against the admitted training/development packs
before freezing. No score-dependent filtering, temperature fitting, prompt tuning
or additional checkpoint search is permitted on the reserved cohort.

Compare three predeclared models under the same constrained label-scoring interface:
the pinned unchanged Qwen3.5-9B foundation, the original supervised step-2,742
adapter, and the single qualifying development-selected history-pilot adapter.
Fix their exact file/tensor identities before the first reserved model call. This
does not compare Qwen's best thinking-mode performance. Require frozen inference
weights, matched short/long padding checks and exact prediction coverage. A partial
run cannot supply a complete comparison. Preserve all failures and partial work.

For tool agreement report equal-server and question-weighted accuracy, log loss,
single-label Brier error, per-server support, and confidence bins with counts.
Confidence bins concern teacher agreement, not real-world success. Report paired
answer-order agreement and probability total variation after aligning option IDs.
For telecom report each family and question kind separately: expected outcome
Brier error and log loss for forecasts, acceptable-choice accuracy and verified
expected utility for procedure choices, and observation-value accuracy. The outcome
scores use the original finite prior, not frequencies manufactured by replay.

The tool advancement target remains at least three percentage points of
equal-server accuracy over the original adapted model, without higher tool log
loss. Telecom must show no worse expected forecast Brier/log loss by horizon and
no worse mean chosen utility or observation-value accuracy. Report these checks
separately; passing this small diagnostic cannot establish broad workflow transfer,
ordered-score quality, multi-question independence or public serving readiness.
Known general tests remain regression evidence, not a fresh final evaluation.

This preparation authorizes no new rental. A scoring run needs a qualified
selection, a fresh budget/rate check within the same original $500, bounded remote
execution, a provider-side deadline and verified artifact recovery. No foundation
model inference on the Mac. Keep raw questions and per-example predictions private.
