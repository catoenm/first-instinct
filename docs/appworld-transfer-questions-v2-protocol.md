# Transfer admission after qualified public evidence and lossless sharing

This stage reuses the completed transfer branches and the separately qualified
public-clock/evidence interface. It preserves rejected v1 admission. It executes
no worlds, calls no model, trains nothing and selects no additional tasks.

The interface qualification must pass with all four reserved programs, all eight
declared histories, zero remaining argument failures and exact round trips for
every candidate. Check the frozen source and candidate hashes, original branch
receipts, clock evidence and existing supervised-pilot data before admitting any
row. The successful qualification used 187 raw variants, with maximum shared
context 7,558 tokens; these are sizing results, not admitted examples or model
performance. A schema-shape loader error before qualification is retained.

Group identical observed inputs before assigning targets, keeping the existing
per-world weighting and uncertainty rules. Shuffle options deterministically by
question identity. Encode using the pinned Qwen3.5-9B tokenizer with an unchanged
8,192-token rejection limit; never truncate. A context overflow now rejects the
whole preparation rather than silently omitting an inconvenient variant.

Retain all four programs, their two histories, decisions, both success outcomes,
useful multi-plan menus and at least one independently replayed successful
alternative each. Every offered decision continuation must match a success
forecast with the exact same decoded public base, commands and underlying-world
population. Check success minus declared attempted-call cost against the
execution-derived decision utility. All public controller computation uses the
losslessly decoded representation; the models will see the shared representation.

Reject any program or exact token-input overlap with the frozen supervised
pilot. All payment programs remain reserved transfer only, including instances
not used here; no row may enter training, replay or checkpoint selection.

Record raw variants, grouped questions, programs, underlying task instances,
history points and earlier execution counts separately. Admission makes no claim
about independent proposal quality, live replanning, calibrated probabilities or
Jev parity. It does not promote a demo checkpoint. Paid model comparison requires
its own frozen protocol, format controls and reconciled remaining original budget.
