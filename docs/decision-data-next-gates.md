# Before the next paid learning comparison

The mixed-decisions-v1 result is closed. All six arms completed, checkpoints were
verified and the rental deleted. No method met the joint transfer gate. Its
publication test is exposed. The intermediate-publication diagnostic and the new
filesystem-scope family address data coverage, not learned performance.

The next bounded local stage is the calendar mechanism previously proposed in
[outcome-v3-data-design](outcome-v3-data-design.md). Reserve the **entire mechanism
for transfer** before model evaluation; no calendar question, trajectory or
wording variant belongs in replay, training, checkpoint selection or development
prompts for the tested model. Authored environment qualification and verifier
negative controls may inspect its ground truth; model results must remain sealed
until a new learning recipe and selection rule are frozen.

Use actual SQLite transactions and a pinned timezone database. Include a few
different task structures: half-open interval overlap versus adjacency, choosing
the intended occurrence of a repeated local time, and rescheduling an existing
event atomically while preserving unrelated rows. These remain one authored
calendar mechanism. Distinct task programs are roots; dates, names, calendars,
costs and hidden availability worlds are related variants, not extra mechanisms.

The installed ToolSandbox checkout provides reminder, messaging, contact and
settings tools, but no calendar availability/transaction tool. Keep using its
actual application implementation for the existing application family. This
calendar candidate uses a real database engine and exact independent predicates,
not another model-authored application simulator. The existing external-project
[review](executable-data-next.md) remains relevant; no unqualified AppWorld or
other benchmark data is silently incorporated.

Freeze a small collection cap before implementation runs. Clone concrete worlds,
execute alternative commands from the same visible history, retain compatible
worlds with differing outcomes, and count observation cost. The verifier must
check exact UTC intervals, the chosen local-time occurrence, legal adjacency,
all-or-nothing replacement, and preservation of unrelated rows. Test no-op,
wrong-time, wrong-calendar, partial-write and collateral-change controls. An
SQL command returning successfully is not task success. Infrastructure exceptions
must fail collection. Timezone version, engine version, source hashes and seed
ownership belong in the receipt.

Require uncertain forecast groups and incorrect irreversible outcomes in the
reserved family, including histories after a real failed command and before a
final commit. Forecasts must state whether they concern immediate execution or
a named continuation. Costs already paid are excluded. Do not selectively drop
hard or uncertain worlds because a model struggles with them.

Before any rental, also review broader training-root coverage. The filesystem
pilot contributes only two task structures and eight world-and-goal tasks; the
publication diagnostic adds histories but no new underlying tasks. Adapt genuinely
different, already-qualified reservation/database mechanisms where compatible,
with independent lineage and clear accounting, rather than calling thousands of
replays new data. Verify the source protocols and actual implementation before
claiming that a prior corpus was included.

Then pre-register one bounded 9B learning comparison from the same original
supervised checkpoint. Preserve general replay. Compare outcome supervision,
reward-only Proximal Policy Optimization, and their combination under paired
seeds/schedules. Record initial component gradient norms and update magnitudes;
a prospective objective-weight or curriculum change must be justified using
training/development data, never the sealed calendar results. Lower probability
error alone is insufficient, as is higher return alone. Keep the joint transfer
and general-retention gates explicit, with a small pilot before scaling.

Reconcile provider charges and storage against the **original cumulative personal
$500 authorization**, not a new budget. No rental is justified until the local
truth, replay, split, token-length and runtime gates pass and the training
allocation/recovery guards are concrete. Further qualified training is already
authorized; no new permission question is needed.
