# Admit paired reserved questions without changing the training contract

After the reserved branch collection finishes, require its independent audit to
qualify all four programs. Reuse the existing application question compiler,
public-argument rules, lossless history encoding, three costs (0.005, 0.05, 0.2),
native label interface and pinned 9B tokenizer. This is a transfer-only admission
attempt, with no model calls, training or hardware rental. A rejection preserves
its counts and explanations; it does not trigger a relaxed automatic retry.

Map the executed redundant-read and authentication-recovery alternatives to the
existing compiler's positive-proposal names. Their actual executed traces become
explicit candidate programs; prove every supplied argument against prior public
evidence or a declared earlier response binding exactly as for the training slice.
Reject unsupported arguments and oversized inputs rather than supplying hidden
reference values, inventing transformations or cropping evidence. A supplied
continuation is fixed and finite; predictions concern completion under that
continuation, not first-call success or adaptive replanning.

Construct continued-success forecasts, independent state-change predicates and
cost-sensitive supplied-plan decisions. Group identical observations over distinct
worlds before forming soft labels. Preserve any disagreement; a single observed
world is not evidence of epistemic certainty. Shuffle option presentation by the
existing deterministic input-identity rule. Keep all retained rows in the reserved
transfer role. Reject overlap with any frozen pilot training or development pool
in task-program identity or actual model token sequence.

Before inference, each of the four programs must retain decision questions,
continued-success forecasts with both outcomes, at least one independently verified
positive alternative and a menu with two genuinely distinct nonempty plans.
Every admitted decision menu must have forecasts for all options over exactly the
same public history and underlying world population. Check the execution-derived
forecast/utility identity. The largest admitted context is 8,192 tokens. Report
token and public-argument exclusions by program, question counts, unique worlds,
history points and branch witnesses separately. Question variants are not tasks.

Preserve rejected candidates privately for diagnosis, clearly marked ineligible.
Only a passing preparation can produce a frozen transfer inference plan. The
fixed model pair, controller definitions, prospective joint gate and unchanged
original compute authorization remain those in the transfer-local protocol.
No candidate is selected or trained against these outcomes.
