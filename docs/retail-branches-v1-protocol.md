# Counterfactuals after writes, refusals and long histories

Qualify a branch interface for future live learning using eight predeclared public
histories from already completed retail executions. Preserve all earlier freezes.
No foundation model, optimizer, GPU rental, official task or reserved mechanism is
used. This remains the existing retail training component, not a new task family.

The eight histories are: successful order-address, profile-address and payment
writes after their inspections; a refused order write; a wrong-scope order write
under a profile-address goal; a cancellation under a payment-migration goal; five
repeated order reads; and five repeated payment-profile reads. Sources and exact
prefix lengths are fixed in the collector before labels are generated. Use their
recorded costs. Prior state and outcome must not choose which histories to keep.

For each history, offer all five existing commands. For every compatible-prior
condition, start each command alternative in a separate process with a fresh copy
of its original epoch-1 world, then replay the exact prefix commands. Compare the
complete resulting public observation to the target history. If it differs, stop
and preserve the screening receipt, but produce no outcome label for that world.
If it matches, execute that alternative once, then stop. At the sixth turn the
existing horizon terminates automatically; do not add a seventh action.

The prefix is a prescribed intervention. Condition the declared uniform original
world prior on its exact observed responses. Do not use how often a controller
visited a world, any policy probabilities, or the outcome to weight compatible
worlds. Worlds that converge to the same current database can still have different
initial preservation obligations: retain each original world and verify against
its original state. Never substitute the post-prefix state for that baseline.

This is precisely a **command-then-stop** forecast. It is not success under a
learned continuation, a command's return code, or the optimal next action when
further repair remains possible. All goal, frame and signed-ledger checks use the
existing independent verifier. Failed or redundant attempts incur their actual
fees; infrastructure errors halt and are not labels.

There are 260 primary world/history/alternative slots and 260 independent process
replays, at most 520 reset executions and 3,120 actor turns/tool attempts. A screened
incompatible world is counted separately from an executed alternative. Use one
worker at a time, the existing retail virtual-environment entry point, 30-second
response limits and the 30-minute/4-GiB/normal-pressure/512-MiB-new-swap supervisor.
No implicit retry. Keep partial journals on any failure.

Before execution, freeze exact source histories, code, tokenizer, worker identity,
question format, prior membership and ceilings. Every question must fit 4,096
tokens without cropping. Afterward independently verify source hashes, prefix and
command histories, state chains, fee/payout accounting, conditional membership,
all alternative coverage and exact replay. Within each original world, the state
after replaying the prefix must match across every alternative and replica.

Produce at most 40 candidate forecast questions: eight histories times five
commands. Group all supporting worlds and histories in the existing retail
ownership component. Average only primary compatible worlds, giving each its
declared prior mass; replay is a determinism check, not added evidence. Do not
collapse distinct original worlds merely because their current state matches.
Report unique histories, compatible branches, screened resets, independent replays,
executed calls, fractional targets and candidate questions separately. Admission
to a training mixture remains a subsequent gate.

Passing qualifies these mutation/refusal/long-history paths and this branch
interface. It does not establish general task diversity, learned performance,
all possible actor histories or a cloud learning runtime. No paid comparison is
launched by this protocol.
