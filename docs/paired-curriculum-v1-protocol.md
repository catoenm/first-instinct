# Paired supervision from existing verified executions

This local stage inventories and indexes existing training-owned evidence after
the completed capacity evaluation. It executes no worlds, loads no foundation
model and allocates no hardware. Earlier sources and their qualified artifacts
remain unchanged. Bound preparation to 7,000 canonical questions, 30,000 cyclic
presentations, 200 MB of new output and the existing local memory/time guard.

Reuse the accepted source registry and its source-audit bindings for configuration,
database repair, application delivery, filesystem mutation and reservations.
Add the already admitted retail questions and the qualified competing-writer
fixed-procedure and optimal-public-continuation questions. Do not open model
scores for any reserved evaluation or change any mechanism's ownership. This
adds no underlying task or independent execution branch.

The optimal-public-continuation source retains its original
`training_mechanism_diagnostic` role in this index. Its mechanism is already used
for training in the completed capacity pilot; indexing its questions here does
not admit them to a new optimizer or turn them into a new evaluation set.

The accepted forecast registry can merge identical public inputs from several
original source groups. Preserve all those aliases. The candidate index binds
every source group in one mechanism to the same whole-mechanism component;
future split admission must resolve the retained aliases as well as the new
component identifier. A new identifier must never hide related earlier data.

Keep the exact original public state, question and descriptions. Preserve the
declared continuation: a fixed procedure, a named command followed by stopping,
or the qualified optimal public continuation. A supervised next-action question
with a specified continuation is not a freely replanning actor prompt. Record
these as separate contracts; never manufacture a missing action or inspection
label from the model, or from forecasts lacking a declared utility comparison.

Outcome distributions, acceptable choice sets and uniform preference distributions
are separate supervision types. Preserve each source's loss meaning, ties and
fractional outcome mass. In particular, uncertain outcomes are not a set of
equally acceptable answers, and a tied action preference is not a success forecast.
Bind each indexed question to its original row, source file and accepted audit.

Pair questions using the same underlying public evidence within each source.
Retail questions retain their common visible context while cost comparisons and
displayed procedures remain in the full question. Do not interpret source-specific
context counts as new worlds or independent mechanisms. Reservations remain
forecast-only unless independently justified decision labels exist.

For each indexed question, prepare all cyclic menu rotations. Each semantic option
must occupy every answer position exactly once. Remap target probabilities and
acceptable indices by semantic identity while preserving state, question and
option descriptions. Keep canonical identities separate from these presentations.
Retokenize every presentation with the pinned 9B tokenizer; reject truncation,
conflicting identical inputs and overlap with the inherited general pools.

Qualification checks target semantics, tied and uncertain targets, complete
position coverage, canonical reconstruction, source ownership and serialization.
Report per-source questions, teacher versus forecast types, ambiguous targets,
public evidence contexts, underlying source census and augmented presentations
separately. Model calls, new branches, optimizer updates and actual training
consumption are all zero.

This is a prepared candidate index, not a training admission or performance
result. Before learning, complete the public tool-contract review (especially
configuration and database-repair effects), full current-mixture split admission,
loss-consumer qualification and a bounded learning recipe. General replay,
separate final-evaluation/recovery windows and unchanged release gates remain
required. Repeating or permuting existing examples cannot establish broader
mechanism transfer.
