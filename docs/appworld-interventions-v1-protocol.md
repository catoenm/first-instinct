# AppWorld execution interventions, prospective local protocol

This stage builds on the existing AppWorld qualification, not another model run.
The expanded screen added eight passing programs to the original two. Three new
programs raised verifier exceptions on no-op controls and join the two existing
quarantines. Reference success alone never overrides a quarantine.

Use only the ten passing upstream training programs. Before recording traces,
assign both phone programs to development and all eight others to training.
Every related task instance and intervention stays with its program. All seven
Venmo programs remain reserved and upstream development/test are untouched.
The phone development scores will be used for selection, not called a final test.

First capture the reference demonstrations in separate local processes. They
are teacher demonstrations, not an independently proposed menu. Save the actual
API responses, public task instruction, and full-state hashes from direct SQLite
reads. Inspect at most 32 task instances, excluding metadata reference counts
above 80 before execution. Limit each world to 96 application calls, 90 seconds,
no outbound sockets, and no pretrained model or paid API calls. Protected task
contents and derived traces remain private in ignored storage.

At most two intervention points per task: the first business mutation, and the
final task completion. Replay in a fresh world, then independently test stopping,
skipping the selected call, an invalid authentication prerequisite where present,
and a wrong target where a different correctly typed identifier has already
appeared in a prior tool response. Never use future responses or private target
identifiers to invent alternatives. The replay continuation is explicitly the
remaining recorded call sequence; it is not adaptive replanning.

Before treating any of these as model inputs, a separate public-information
closure check must establish every supplied argument and redact credentials.
Reference-assisted proposals must be identified as such, with coverage measured
separately. Do not claim these are general dynamic tool proposals. If a remaining
script depends on an unavailable argument, it cannot silently become an actor
continuation. Either provide an explicit, fully specified public script or reject
that row. No model output supplies truth.

Reference replay must match the recorded responses, final semantic table hashes,
and task assertions. Inject an unrelated record change after a reference succeeds
as an additional verifier control; this injected fault is never an actor option.
Task assertions plus a direct SQLite frame check must reject collateral changes.
Record verifier exceptions as missing labels and quarantine that program from
supervision until repaired and requalified. The proportion of assertions passed
is never a probability target. A direct table-difference check is only a state
preservation check, not a universal semantic task verifier.

The collection ceiling is 32 captures + 32 exact replays + 32 collateral controls
+ 32 × 2 × 4 intervention branches = 352 worlds, followed by at most one independent
replay of each retained intervention (256 more worlds). Count attempts, successful
receipts and verifier failures separately. Do not duplicate existing substrate
qualification worlds or overwrite failed attempts.

Training remains gated on at least eight usable training programs, sound negative
controls, public-information closure, independent branch replay, grouped splits,
token limits and general-task replay/retention. If the available programs fail
those checks, continue data work rather than rent hardware to consume bad labels.
The next paid pilot, when ready, keeps the original step-2742 9B adapter and the
remaining original cumulative $500 authorization. No new budget is created here.
