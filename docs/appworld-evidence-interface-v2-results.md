# Public evidence and full-context transfer admission

The previously rejected payment transfer set now passes local admission, without
changing its four selected programs, execution outcomes or 8,192-token ceiling.
No transfer model result was available when this report was written. The original
v1 rejection and all its artifacts remain preserved.

Two defects in the input interface had blocked otherwise verified tasks. The
reference demonstrations used dates from the simulated clock without recording
that clock as an observation. Some amounts were explicit currency literals inside
earlier note text, which the old scalar-only evidence checker did not recognize.
Neither issue justified copying private constants into a question.

Eight fresh evidence-control worlds—two replays for each of the four existing
instances—made 24 public clock reads and 348 total application calls. They loaded
no task ground truth. Each read preserved all semantic database records, both
independent replays agreed, and all replayed prefix responses and history-point
states exactly matched the already executed branches. These are evidence checks,
not new tasks or outcome labels.

The revised compiler records typed argument witnesses. A currency witness points
to a prior response, its exact text span and decimal value. A relative-date witness
uses the observed clock and explicit goal wording; a separate calendar walk checks
the date arithmetic. Each historical command is checked against its own earlier
prefix, so evidence learned later cannot justify an earlier call. This resolved
all seven previously ungrounded argument occurrences across the eight histories.

The context representation shares exactly repeated public JSON subtrees in a
readable catalog. It neither summarizes records nor removes commands. Exact
round trips preserve types, order and missing values; decoding before controller
computation preserves commands, call costs and selections. Catalog construction
uses public input only, without labels or branch-quality identifiers. Models see
the same shared input; this does **not** imply they predict the same way as with
expanded input, which the next experiment explicitly tests.

All four programs retain their two histories, positive and negative outcomes,
useful multi-plan menus and successful alternative executions. Program and token
overlap checks against the frozen supervised pilot passed. Payment programs remain
transfer-only. Raw tasks, traces, questions, solutions and predictions stay private.
The public receipts contain aggregates and hashes only.

Eleven fixture tests cover evidence forgery, future references, calendar boundaries,
catalog spoofing and cycles, exact decoding, controller invariance and conjunctive
evaluation gates. A schema-shape loader error and a retention-input validation
error occurred before their respective package freezes; both were retained and
corrected locally, with no model calls or hardware rental for those failures.

The separately frozen next comparison uses the original adapter and the already
selected update-40 adapter. It includes both representations of the same phone
development questions and repeats general retention. It is inference only, capped
at $12 from the original remaining authorization. The four-world transfer set is
too small for population-wide calibration claims, and its supplied continuations
remain reference-assisted rather than independently proposed commands.
