# Question interface over qualified competing-writer executions

Reuse the [qualified executor](revisioned-sqlite-v1-results.md) without rerunning
its 96 primary branches or 96 replays. Preserve the parent freeze and all source
files. The six initial visible contexts are two user goals crossed with three
cost profiles. Each has the same history in two equally probable hidden schedules.
Keep all goals, schedules, costs and option permutations in one training-candidate
ownership group. Nothing in this stage is admitted to a training run or reserved
for a fresh transfer claim.

Prepare 138 canonical questions with these explicit meanings:

| Kind | Count | Label source and scope |
| --- | ---: | --- |
| Next command | 6 | Compare all six commands under the **same displayed fixed continuation**: read, conditional write, finish. Termination stops the sequence. These are not unrestricted optimal-action labels. |
| Procedure selection | 6 | Compare exactly the eight executed witness procedures by expected verified utility. |
| Immediate goal status | 36 | Independently check the actual database snapshot immediately after the named command, before any later action. No synthetic stop execution is invented. |
| Command return code | 36 | Distribution over the actual first command's return code, separately from goal status. |
| Goal status after procedure | 48 | Check the final state after the named complete procedure. |
| Observation-cost comparison | 6 | Compare read-then-conditional-write with the best of the four explicitly listed one-command-then-stop procedures. This is not global-optimal information value. |

The fixed continuation is a specified hypothetical procedure, not a recommended
policy. It may violate the revision-limited goal after a fresh read. Correct
answers must account for that behavior. Immediate snapshots already present in
valid longer traces can support immediate-state questions, but must not be
reported as newly executed terminating branches.

The public state contains the exact goal, factual tool contract, cached values,
history, costs, remaining horizon and command descriptions, plus public procedure
definitions. It must round-trip to the original visible state exactly. Private
world identity, outcomes, source IDs, labels and future observations remain in
sidecars. Require identical rendering across compatible worlds **before** the
future command or procedure is considered. Replays contribute zero extra prior
mass; each primary world contributes one half to each relevant comparison.

Realized outcome distributions use soft targets. Decision and comparison labels
use sets of equally best answers within the declared menu, not fake probabilities
of success. No model prediction may provide a target. Audit input identity,
source receipts, priors, acceptable choices and targets separately. Corrupted
labels, weights, replica ownership, command horizon and private input fields must
be rejected. Reverse each answer menu as 138 additional formatting diagnostics;
keep those distinct from canonical candidate questions and future consumption.

Use only local tokenizers. Qualify all 276 presentations against the pinned Qwen
formatter without truncation at 4,096 tokens. Also measure the pinned native Laya
formatter and require exact tokenizer parity. Report its full-information
coverage explicitly: incompatible inputs must not silently enter a future
cross-model comparison. Do not expand native budgets, clip descriptions or drop
rows to manufacture compatibility. This stage permits no model weights on the
Mac, model calls, new environment executions, optimizer steps or GPU rental.

Freeze the source, source-receipt identity and this protocol before qualification.
Run under the existing local CPU guard. Preserve failed attempts. Publish only
aggregate counts and scope; raw questions and receipts stay local. Further
training admission requires ownership/deduplication checks against the existing
mixture and an explicit learning protocol. A small candidate set from one authored
mechanism is not evidence of general capability.
