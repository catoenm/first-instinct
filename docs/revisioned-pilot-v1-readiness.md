# The integrated 9B pilot is launched

One H200 has been allocated at $4.59/hour. The launch first performs remote
runtime and real-model checks, then runs the three planned learning methods at
two paired seeds. This report records launch readiness, not training results.

The training pool contains 5,654 execution-verified forecast questions across
seven groups, 268 existing shell/application case variants, the qualified retail
and database live actors, and a 4,096-question general replay pool. The database
addition is 3,144 questions from one mechanism and four world/goal tasks. Earlier
overlapping initial-state forecast variants are excluded from this mixture.

New inputs passed admission against 842,299 stored presentations with zero exact
collisions. Reserved evaluation was used only for fingerprints. All 308 exposed
report forecasts retain their complete public tool contract; the live report
actor receives the same additional public mechanics through an explicit input
transformation. Token parity passed without cropping. General retention remains
622 questions. This exposed development cohort is not fresh transfer.

The exact 1,002-file runtime/data bundle passed 15 tests in an isolated local
directory. Data assembly and bundle checks stayed below 1 GiB process-group memory
with no added swap. The initial preparation attempt stopped on a manifest-schema
assumption before creating a dataset; that directory and the original manifests
are preserved. The corrected reader recognizes the paired diagnostic's source
files inside its file manifest. The first wrapper test also used an invalid
one-option fixture; it was corrected to a valid two-option question before freeze.

The pilot reserves $30 from the same existing authorization: up to $27 of compute
and $3 for storage/recovery, with an independent five-hour shutdown deadline.
Each arm is bounded to 27 minutes and at most 16 updates. It retains the joint
decision/forecast improvement and general retention gates. No automatic rental
extension or larger run follows failure. The original supervised checkpoint
remains selected until evaluated evidence supports a change.
