# Admission to a separate training staging index

Preserve the qualified 138-question interface and every older experiment.
Create a new staging index; do not append to a running or frozen training pack.
All questions retain one ownership group and remain a training-only extension
of database and stale-evidence work. The authored-executor overlap review does
not establish semantic novelty across every natural-language example.

Verify the question freeze, raw candidate bytes and previously qualified token
identities. Compare all 276 canonical/reversed token fingerprints with frozen
general training/evaluation, assembled release training/development, history
training/development, live-tool forecasts/replay/retention, and exposed paired
forecast inputs. Also compare reserved evaluation token fingerprints only: do
not render or export reserved question text, use labels for selection, generate
predictions or open model scores. Preserve every existing role.

Bind each source file to its own manifest and the prospective admission plan.
Stream the comparisons under the local guard, with a maximum one million rows.
Abort admission on source changes, missing token identities, any exact candidate
collision or existing ownership identifier collision. Report scanned rows as
presentations, not unique tasks or examples consumed by a model.

After passing, stage the 138 canonical questions only. Reversed menus remain
formatting diagnostics. Preserve every input, target and execution reference.
The 120 distribution questions keep separate horizon types: immediate goal
state, immediate command response, and terminal outcome under the displayed
procedure. The 18 acceptable-choice questions remain sets of maxima within the
declared comparison. Never turn those sets into empirical outcome probabilities.

The current frozen live learner accepts only command-then-stop and displayed
continuation contracts, so this index alone is **not ready for that trainer**.
A separately tested consumer must support the new immediate semantics explicitly.
Do not silently relabel them or treat fixed-continuation action labels as live
rollout rewards. A future run still needs general replay, matched controls,
independent transfer and decision/probability/retention checks, runtime
qualification, exact lineage and a bounded compute plan. No GPU, model call,
environment execution or optimizer step is authorized by this data artifact.
