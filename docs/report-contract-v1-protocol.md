# Public report-tool contract qualification

This stage investigates a post-hoc data-interface hypothesis from the completed
Laya/Qwen baseline. It does not alter that benchmark, change its executed labels,
train a model, open reserved scores or rent hardware.

Prepare a separate rendering of all 308 exposed report forecast questions. Append
the same factual tool contract to every original state, preserving the original
state, question and options verbatim. The contract must describe the executor's
public argument mapping, observations, failure preconditions, automatic computation,
terminal effects and cost/turn rules. It must not contain per-world file values,
the preferred target, a forecast distribution or a correct-answer annotation.
Both compatible hidden worlds receive identical text. Do not target only the forty
ambiguous examples or remove difficult cases.

Audit the proposed contract against the frozen implementation and the existing
execution receipts. Independently predict immediate return codes, state-flag
effects and termination from each visible pre-action state; compare those with
recorded executions. Reconstruct final-state outcome labels using the existing
independent receipt audit, then reproduce every grouped soft target from its
original source members. A model prediction never supplies a label.

This first qualification reuses existing executions: report historical branches,
commands, physical worlds, cases and visible forecast questions separately from
new executions, new tasks and training consumption, which are all zero. It does
not establish fresh replay across operating systems or a new causal mechanism.

Check complete-information native Laya formatting and exact Qwen tokenization for
both original and augmented versions. No cropping or token-budget increase is
allowed. Failure means revise the proposed input format in a separately recorded
pre-model stage; it does not justify selectively scoring only shorter inputs.
Tokenization runs under the existing Mac CPU guard and loads no foundation weights.

Only after this local stage passes may a separately frozen, bounded paired
inference protocol compare contract-present with contract-absent inputs. Keep
checkpoint/runtime/temperature/option order fixed, score the entire same cohort,
and report both probability quality and answer changes. These remain exposed
diagnostics. Improvement would support an interface explanation on this cohort;
it would not prove general calibration, improved learning or transfer.
