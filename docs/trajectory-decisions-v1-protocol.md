# Local qualification of decisions inside execution histories

This follows the completed mixed-decisions-v1 comparison. No rental or optimizer
is launched. Keep its sources, checkpoints and exposed transfer results intact.
Use the remaining original authorization only after a new learning protocol and
local gates pass.

First, repair a demonstrated coverage gap using the existing publication engine.
Replay actual histories ending after staging and validation, after restaging
that makes validation stale, and after a failed premature commit. Ask the same
three question types at each resulting visible history: next action, consequence
of a named action, and value of another observation. Reuse the current equal
prior over compatible file worlds and explicit continuation contracts. Execute
every candidate/continuation in a freshly reset world, and replay the whole
branch independently a second time. No model creates targets or decides which
labels to retain.

This is an **exposed-mechanism diagnostic**, not a new transfer benchmark or
permission to silently append data to a completed run. Keep all related roots,
worlds, goals, costs and histories together. Existing publication roots never
become a pristine test again. Use hidden, fresh, contradictory and expensive
observation regimes, four underlying world-and-goal tasks, three intermediate
histories, seven options and three continuations: at most 1,008 distinct branches,
2,016 verification executions and 25,000 actual commands. Prefix replay is
counted separately and is not a new independent task.

Forecast `stop_now` means the named action followed by stopping, with no further
mutation; the bookkeeping stop has zero cost. The other forecasts name either
the existing evidence-following continuation or the no-more-observations
continuation, respecting the six-decision total horizon. Future costs exclude
history that has already happened. A next-action target maximizes expected
executed reward under its declared continuation across compatible worlds. An
observation-value target compares the inspection continuation with the best plan
forbidden to acquire more observations. Neither is an unrestricted optimal policy.

Qualification must independently reconstruct every visible history and terminal
reward from the saved files, verify initial fixture hashes, preserve protected
bytes, confirm that a replay matches, and regenerate every label from receipts.
Require all three outcomes, contradictory outcomes under identical public input,
current observations resolving uncertainty, and cost-sensitive decision changes.
Reject tampered outcomes, command histories, past/future cost accounting, missing
counterfactuals and duplicate receipts. Failed infrastructure is never an outcome.
Stop collection on any gate failure and retain its failure record.

Second, locally qualify a genuinely different filesystem mechanism: mutation
scope through hard links and separate copies. Identical visible contents can
hide different file identity. Updating one path in place can change another
name; atomic replacement can break a required shared identity. Opposite user
goals must change which operation is correct. Verify actual bytes and alias
relationships outside the acting process, preserve unrelated files, and charge
for inspection. A known sufficient state should prefer acting; expensive or
unnecessary inspections should favor acting or stopping. Use only an authored
catalog in temporary worlds, with no model text executed.

This filesystem work is a candidate mechanism, not automatically a new test.
Reserve ownership before any model evaluation, use several distinct task
structures rather than pathname substitutions, and establish local Linux parity
before training. Existing ToolSandbox execution remains the application source;
we are not replacing it with simulated model labels. Harbor is reserved for the
separate stage that executes arbitrary proposed command menus, with proposer
coverage measured independently of selector quality.

Before the next paid comparison, freeze broader roots/mechanisms, a new whole
transfer mechanism with uncertain and incorrect-outcome groups, equal-start 9B
arms, general replay, context-length limits, gradient balance diagnostics,
consumption ledgers and joint advancement criteria. Publication results and this
local qualification may guide data design, but never choose a checkpoint on the
new reserved test. Do not simply rerun the failed mixed pilot for longer.
